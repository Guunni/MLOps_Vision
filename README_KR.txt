WELCOME 39~49초 자동 적용 도구

1) 압축을 풉니다.
2) RUN_WELCOME_PICKER.bat 를 더블클릭합니다.
3) 첫 번째 선택창에서 원본 영상을 선택합니다.
4) 두 번째 선택창에서 원하는 문구 이미지를 선택합니다.
5) 선택한 이미지가 영상의 39.00~49.00초에 자동 적용됩니다.

현재 설정
- 등장: 39.00~39.85초
- 유지: 39.85~48.15초
- 퇴장: 48.15~49.00초
- 가로 중앙 정렬
- 4K 영상 기준 세로 위치 약 y=1028px
- 이미지 높이 520px
- 오디오 원본 유지
- H.264 / CRF 14 / faststart
- 결과 파일: [원본파일명]_WELCOME_39_49.mp4

권장
- 투명 PNG를 쓰면 가장 깔끔합니다.
- 검은 배경 이미지도 colorkey로 어느 정도 자동 제거됩니다.
